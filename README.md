# Higor Viagens

Site estático feito com HTML, CSS e JavaScript.

## Arquivos principais

- `index.html`: estrutura do site
- `style.css`: estilos principais, tema claro/escuro e responsividade
- `elegant-carousel.css`: estilos do carrossel
- `elegant-carousel.js`: comportamento do carrossel
- `logo.png`, `grupo.jpg`, `disney.jpg`, `atendimento.jpg`: imagens usadas no site

## Como abrir

Abra o arquivo `index.html` no navegador ou use a extensão Live Server no VS Code.

Não é necessário instalar dependências nem rodar build.
